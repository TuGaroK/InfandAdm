# Калькулятор накопленной оценки

Учебный FastAPI-сервис рассчитывает накопленную оценку по трём предметам:
дискретным и непрерывным структурам, программированию на Python, инфраструктуре
и администрированию. Можно получить формулу предмета и рассчитать полный или
частичный вклад уже известных оценок.

За основу взят `app_final.py` из архива занятия 4, предоставленного
преподавателем. Предметный каталог, расчёт на `Decimal` и проверки входных
данных добавлены для этого проекта.

## Подготовка

Проект проверяется с Python 3.12. В PowerShell из корня репозитория:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Для запуска тестов вместо последней команды установите зависимости разработки:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
```

## Настройки окружения

Доступны следующие переменные:

- `APP_NAME` — название сервиса, по умолчанию `Калькулятор накопа`;
- `APP_VERSION` — версия API, по умолчанию `0.1.0`;
- `LOG_LEVEL` — уровень логирования, по умолчанию `INFO`.

Файл `.env.example` содержит только примеры и автоматически не загружается.
В PowerShell переменные нужно задать в текущем сеансе перед запуском:

```powershell
$env:APP_NAME = "Калькулятор группы"
$env:APP_VERSION = "0.1.0"
$env:LOG_LEVEL = "INFO"
.\.venv\Scripts\python.exe -m uvicorn app_final:app
```

Неизвестное значение `LOG_LEVEL` заменяется на `INFO` с предупреждением.

## Запуск

Обычный запуск без автоматической перезагрузки:

```powershell
.\.venv\Scripts\python.exe -m uvicorn app_final:app
```

Для разработки:

```powershell
.\.venv\Scripts\python.exe -m uvicorn app_final:app --reload
```

После запуска доступны:

- приложение: <http://127.0.0.1:8000/>

## API предметов

- `GET /subjects` — список доступных предметов;
- `GET /subjects/{subject_id}` — формула, компоненты и правило округления;
- `POST /subjects/{subject_id}/calculate` — расчёт накопленной оценки.

Пример полного расчёта:

```json
{
  "grades": {
    "homework_avg": 6.5,
    "mini_tests_avg": 8.5,
    "independent_avg": 7,
    "exam": 8
  }
}
```

Для частичного расчёта можно передать только известные оценки:

```json
{
  "grades": {
    "hw1": 6.5,
    "hw2": 8.5
  }
}
```

Отсутствующий компонент и `null` означают неизвестную оценку, а `0` — известную
нулевую оценку. Ответ содержит вклад каждого компонента, сумму до ограничения
`raw_score`, ограниченный сверху значением 10 `score`, список пропусков и признак
полного ввода.
`rounded_grade` не заменяет дробный `score`: он заполняется только для полного
ввода и только у предметов с подтверждённым арифметическим округлением.

Оценки должны быть конечными JSON-числами от 0 до 10 включительно. Сумма весов
дискретки равна 1.1 и не нормируется: ограничение 10 применяется к результату,
но введённая оценка выше 10 считается ошибкой.

При запуске, остановке, успешном расчёте и ошибке сервис пишет сообщение в
консоль без оценок и полного тела запроса. Уровень сообщений задаёт `LOG_LEVEL`.
